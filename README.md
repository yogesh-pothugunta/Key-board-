# FreeFix Keyboard (v0.1)

Android Studio లో ఓపెన్ చేసి రన్ చేయండి:
1. Android Studio -> Open -> ఈ ఫోల్డర్ ఎంచుకోండి. Gradle sync అయ్యే వరకు ఆగండి (ఇంటర్నెట్ కావాలి).
2. ఫోన్‌లో Developer options -> USB debugging ఆన్ చేసి, USB తో కనెక్ట్ చేసి Run ▶ నొక్కండి.
3. యాప్ ఓపెన్ అయ్యాక: "1. Keyboard ఆన్ చేయండి" -> "2. FreeFix ని ఎంచుకోండి".
4. "Key తీసుకోండి" నొక్కి aistudio.google.com లో ఫ్రీ API key తీసుకుని, యాప్‌లో పేస్ట్ చేసి Save -> Test నొక్కండి.
5. ఏదైనా చాట్‌లో టైప్ చేసి Fix / Formal / Casual నొక్కండి. ✓ నొక్కితే టెక్స్ట్ మారుతుంది, ↶ Undo తో వెనక్కి వస్తుంది.

తెలుగు అక్షరాలు టైప్ చేయడానికి 🌐 నొక్కి మీ తెలుగు కీబోర్డ్ కి మారి, టైప్ చేసి, మళ్ళీ FreeFix కి వచ్చి Fix నొక్కవచ్చు.
Model పేరు పనిచేయకపోతే (404/400 లోపం) AI Studio లో ఇప్పుడున్న ఫ్రీ Flash/Flash-Lite మోడల్ పేరును సెట్టింగ్స్ లో మార్చండి.
